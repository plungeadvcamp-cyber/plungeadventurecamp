# 🌊 Plunge Adventure Camp

A responsive and interactive website for Plunge Adventure Camp, designed to inspire transformation through adventure, community, and faith-based experiences.

🚀 Features

* Responsive design for desktop, tablet, and mobile devices
* Hero section with background video
* Featured Camp Event section
* Adventure Activities showcase
* "What Makes Us Different" section
* Interactive Image Gallery
* Testimonials page
* Contact page with WhatsApp and Email integration
* Smooth hover animations and transitions
* Mobile-friendly navigation menu

🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Font Awesome
